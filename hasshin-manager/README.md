# 📣 発信マネージャー

**YouTube / X(Twitter) / note / Instagram の発信を、ひとつの画面で管理するアプリ。**
個人開発を伸ばすための「**林インターンメソッド**」を内蔵。ネタ出しから公開、数字の記録までを回して、継続と成長を仕組みにします。

## こんな人に

- 4つのSNSを片手間でやっていて、いつ何を出したか散らかっている
- 「毎日発信したいのに続かない」
- 個人開発（アプリ・サービス）をちゃんと届けて伸ばしたい

## 使い方

1. `index.html` をブラウザで開く（スマホ推奨）
2. 下のタブで4つの画面を切り替えます
   - **🏠 ホーム** … 今日の林メソッド、連続発信日、各SNSの数字、直近の予定
   - **📝 投稿** … ネタを追加し、`アイデア → 下書き → 予約 → 公開済み` と進める
   - **📈 数字** … フォロワー/登録者数を記録して成長グラフで見る
   - **🔥 メソッド** … 林インターンメソッド5つの型と、週1の振り返り
3. データはこの端末の中だけに保存されます（サーバー送信なし）

### スマホアプリとして使う（おすすめ）

1. Safari / Chrome で `hasshin-manager/index.html` を開く
2. 共有メニュー →「ホーム画面に追加」
3. ホームのアイコンから起動（オフラインでも動きます）

## 🎓 林インターンメソッドとは

「優秀なインターンのように、毎日ちゃんと手を動かして報告する」を発信に当てはめた、個人開発を伸ばすための5つの型です。

1. **毎日1発信（Ship Daily）** — 完璧じゃなくていい。「今日やったこと」を1つ必ず出す。継続が信用になる。
2. **1ネタ4展開（Repurpose ×4）** — 1つのネタを YouTube＝長編 / X＝要点とフック / note＝深掘り / Instagram＝ビジュアル に形を変えて配る。
3. **数字で振り返る（Review Weekly）** — 週1でフォロワーとインプレを記録し、伸びた投稿の「型」をメモする。
4. **勝ち型を量産（Double Down）** — バズは運、再現は技術。伸びた型は迷わず繰り返す。
5. **返信で仲間を作る（Engage）** — 毎日1人に絡み、コメントは必ず返す。発信は独り言じゃなく会話。

> ※ このメソッドは、個人開発／ビルド・イン・パブリックでよく語られる成長原則を、このアプリ向けに1つの型としてまとめたものです。

## できること

- 4プラットフォーム（YouTube / X / note / Instagram）横断の発信管理
- カンバン式のステータス管理（アイデア → 下書き → 予約 → 公開済み）
- 1ネタを複数SNSに展開するためのプラットフォーム選択
- フォロワー数の記録と、プラットフォーム別の成長グラフ（SVG）
- 今日のメソッド・週次振り返りのチェックリスト
- 連続発信日（ストリーク）の自動集計
- オフライン動作（PWA / Service Worker）
- データは端末内のみに保存（`localStorage`）

## 動かし方（開発）

静的サイトなので、ファイルを開くだけでも動きます。
Service Worker を有効にするには `https` か `localhost` での配信が必要です。

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000/hasshin-manager/
```

## 制限と今後

- **自動投稿はしません。** 各SNSへの実投稿は手動で行い、このアプリは計画・記録・継続の管理に専念します（API連携での自動投稿にはサーバーと各社の審査が必要）。
- 数字は手入力です。将来的に各SNSのAPI連携で自動取得する余地があります。
- データは端末内のみのため、機種変更時はエクスポート機能（今後追加予定）が必要です。
