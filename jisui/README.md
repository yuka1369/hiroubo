# 🍳 じすいっち

**推しのレシピで、今週のごはんを自動でくむ自炊アプリ。**
好きなYouTuber・インスタを登録 → レシピをカテゴリで分類 → 平日は「簡単＆栄養」、土日は「30分でできる作り置き・冷凍ストック」で1週間の朝・昼・夜を自動で提案。決定すると買い出しリストと合計金額まで出します。

## できること

- **推しを登録**：YouTuber / Instagram / TikTok を登録し、担当カテゴリを割り当て
- **6つのカテゴリで分類**
  - ⚡ 1分限界料理
  - 🧊 作り置き・冷凍ストック
  - 🥗 栄養料理
  - 📖 漫画料理
  - 🎉 食の楽しみ料理
  - 💰 節約料理
  - 🪙 朝昼晩400円以下（1食ワンコイン以下・値段で自動判定する横断カテゴリ）
- **今週の献立を自動推薦**
  - 平日（月〜金）：簡単＆栄養バランス重視で朝・昼・夜を提案
  - 土日：30分以内で作れる冷凍ストック・作り置きを提案
  - **初期設定（デフォルト）で朝昼晩すべて1食400円以下**にしぼって提案（チェックを外すと全レシピから提案）。400円を超える食事は赤色で表示
- **推しのレシピだけで組む**オプション
- **1食ずつ差し替え**（🔄）できる
- **買い出しリスト＆金額**：決めた献立の材料を自動集計し、合計金額を算出
- **予算で決定**：1週間の予算を入れると、超えたぶんは節約系に寄せて予算内におさめる
- レシピ・推しは自分で追加OK。データはこの端末の中だけに保存（サーバー送信なし）
- オフライン動作（PWA / Service Worker）

## 使い方

1. `jisui/index.html` をブラウザで開く（スマホ推奨）
2. **⭐推し** タブで好きなクリエイターを登録（サンプルも入っています）
3. **🗓️献立** タブで「週のはじまり」と（任意で）予算を入れて **✨今週の献立を推薦する**
4. 気に入らない食事は 🔄 で差し替え
5. **🛒 買い出しリストを作る** → 材料と合計金額をチェックしながら買い物

### スマホアプリとして使う

1. Safari / Chrome で `jisui/index.html` を開く
2. 共有メニュー →「ホーム画面に追加」
3. ホームのアイコンから起動

## 動かし方（開発）

静的サイトなのでファイルを開くだけで動きます。Service Worker を使うには `https` か `localhost` 配信が必要です。

```bash
python3 -m http.server 8000   # → http://localhost:8000/jisui/
```

## 制限と今後

- いまは YouTube / Instagram の内容を**自動取得はしません**（外部APIとサーバーが必要）。推しの登録＝「どのカテゴリの担当か」の記録として使い、レシピは初期サンプル＋自分で追加する形です。将来的に投稿URLからレシピを取り込む拡張が可能です。
- 金額は「材料の目安価格」を積み上げた概算です。実際の店頭価格とは異なります。
