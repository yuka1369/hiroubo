# 📞 CallMe

**時間の少し前に「電話がかかってくる」アラームアプリ。**
ADHDなどで通知を見流してしまいがちな人向けに、フルスクリーンの着信画面・鳴り続ける着信音・バイブで「本物の電話みたいに無視しづらく」時間を知らせます。

## こんな人に

- 気づいたら予定の時間を過ぎている
- 普通の通知バナーはスルーしてしまう
- 「あと5分」の合図があれば動き出せる

## 使い方

1. `index.html` をブラウザで開く（スマホ推奨）
2. **やること**・**予定の時刻**・**何分前に電話する？** を入れて「追加する」
3. 時間になると着信画面が出て、着信音とバイブが鳴ります
   - **出る** → 「時間だよ！」のメッセージ
   - **あとで(5分)** → 5分後にもう一度かかってくる（スヌーズ）
4. 60秒放置すると自動で5分後に再着信します

### スマホアプリとして使う（おすすめ）

1. Safari / Chrome で開く
2. 共有メニュー →「ホーム画面に追加」
3. ホームのアイコンから起動して「🔔 通知を許可する」を押す

## できること

- 単発 / 曜日ごとの繰り返し
- 0〜60分前のリード時間（何分前に鳴らすか）
- 着信音（合成音・音源ファイル不要）＋バイブ＋通知
- 画面ロック防止（Wake Lock 対応端末）
- オフライン動作（PWA / Service Worker）
- データはこの端末の中だけに保存（サーバー送信なし）

## 動かし方（開発）

ただの静的サイトなので、サーバー不要でファイルを開くだけでも動きます。
Service Worker と通知をきちんと使うには `https` か `localhost` での配信が必要です。

```bash
# 例: どれか1つ
python3 -m http.server 8000     # → http://localhost:8000
npx serve .
```

## 制限と今後

- **このタブ（アプリ）を開いている間**が一番確実に鳴ります。完全にアプリを閉じた状態でのバックグラウンド着信には、プッシュ通知サーバーが別途必要です。
- マナーモード時は音が出ないことがあります。大事な予定はマナーを解除してください。
- **本物の電話番号への発信**（Twilio等）に対応させる場合は、発信用のサーバーと契約が必要です。いまはアカウント不要で使えるアプリ内着信の形にしています。
