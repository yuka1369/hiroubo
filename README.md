# ✨ ときめき片づけ

**こんまり式（近藤麻理恵さん流）の「一気に、正しい順番で」片づけるための断捨離アプリ。**
モノを一つずつ手に取り、「ときめくか」で残すか決める ── その体験をアプリで案内します。

## 正しい順番

片づけは “場所ごと” ではなく **“モノの種類ごと”**、しかも決められた順番で進めるのが基本です。

1. 👕 **服**
2. 📚 **本**
3. 📄 **書類**
4. 🧴 **小物**（コモノ）
5. 💌 **思い出の品**

判断がやさしいものから始めて、最後にいちばん難しい「思い出」へ。
このアプリでは、**前のカテゴリーを完了するまで次はロック**されます。

## 使い方

1. `index.html` をブラウザで開く（スマホ推奨）
2. 「服」を開き、**STEP 1** で家じゅうの服を一か所に集めて、チェックを入れる
3. **STEP 2** で一つずつ手に取り、**💗 ときめく（残す）** か **👋 ありがとう（手放す）** を選ぶ
4. 「このカテゴリーを完了する」で次のカテゴリーが開く
5. 5つすべて終えたら 🎊

### スマホアプリとして使う

1. Safari / Chrome で開く
2. 共有メニュー →「ホーム画面に追加」
3. ホームのアイコンから起動

## できること

- こんまり式の 5 カテゴリーを **正しい順番でガイド**（順番ロック付き）
- 各カテゴリーの「集める」チェックリスト＋ヒント
- 一品ずつの **ときめきチェック**（残す／手放すを記録）
- 残した数・手放した数の集計、全体の進捗バー
- 完了ごとの お祝い演出 🎉
- データはこの端末の中だけに保存（`localStorage`・サーバー送信なし）
- オフライン動作（PWA / Service Worker）

## 動かし方（開発）

静的サイトなので、ファイルを開くだけでも動きます。
PWA（オフライン・ホーム追加）をきちんと使うには `https` か `localhost` での配信が必要です。

```bash
# 例: どれか1つ
python3 -m http.server 8000     # → http://localhost:8000
npx serve .
```

| ファイル | 役割 |
|---|---|
