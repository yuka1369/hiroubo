# 🌾 掴め！牧歌ライフ！

**旦那様と畑をたがやし、しゅうかく物で研究をすすめ、ふたりの牧歌ライフを育てる**ほのぼの経営シミュレーション。

「旦那様と牧歌ライフし研究をしてくらす」——その願いを、そのまま小さなゲームにしました。
アカウント不要・オフラインでも動く、1画面完結のブラウザアプリ（PWA）です。

## 遊びかた

1. `index.html` をブラウザで開く（スマホ推奨）
2. **タネを選んで空いた畑をタップ** → 少し待つと実ります → **もう一度タップで収穫** 🧺
3. **🔬研究ラボ**で「研究する」を押し、しゅうかく物を研究P（🔬）に変える
4. 研究Pで**研究ツリー**を開放
   - 🌱 肥料で成長スピードUP／🚜 畑を拡張
   - 🍅🍓🎃 新しい作物／🐔🐄 家畜小屋（自動でしゅうかく物が届く）
   - 📚 旦那様の書斎・🌾 風車小屋 …
5. **☕ 旦那様とお茶する**と ❤️ がたまり、収穫と研究にボーナス（＋やさしいひとこと）
6. すべての研究をやりきると **🏡「ふたりの牧歌ライフ」完成！**

畑や家畜は**閉じているあいだも時間で育つ**ので、ときどき覗きにくる遊びかたもできます。

## こんな要素

- タップで植えて収穫する、テンポのいい畑パート
- しゅうかく物 → 研究P → 開放、のごほうびループ（研究10種）
- にわとり・うしの**放置収穫**
- 旦那様との**お茶＆セリフ**、❤️で全体がちょっと有利に
- 日数・季節（はる/なつ/あき/ふゆ）と日記のログ
- データはこの端末だけに自動保存（サーバー送信なし）
- オフライン動作（PWA / Service Worker）

## スマホアプリとして使う（おすすめ）

1. Safari / Chrome でこのページを開く
2. 共有メニュー →「ホーム画面に追加」
3. ホームのアイコンから起動

## 動かし方（開発）

静的サイトなので、ファイルを開くだけでも動きます。
Service Worker まで使うには `https` か `localhost` での配信が必要です。

```bash
# このフォルダで、どれか1つ
python3 -m http.server 8000     # → http://localhost:8000
npx serve .
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `styles.css` | 見た目（牧歌調のあたたかい配色） |
| `app.js` | ゲームロジック・保存・時間の進行 |
| `manifest.json` | PWA設定 |
| `service-worker.js` | オフライン対応 |
| `icon.svg` | アイコン |
