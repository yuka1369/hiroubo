# 💖 目指せ！爆美女！

**30日間で「なりたい自分」に近づく、自分みがき育成ゲーム。**
毎日ひとつずつ行動を選んで確認すると、ステータスが上がり、ストーリーが進みます。憧れのアイドルやライバルとの出会いを経て、最終日のステージを目指しましょう。

> ⚠️ 登場する女の子（MINA・ここ・レイナ）は、実在の人物とは関係のない**架空のオリジナルキャラクター**です。

## あそびかた

1. `index.html` をブラウザで開く（スマホ推奨）
2. 名前を決めて「決意する」
3. 毎日、**行動力（●●●）**の範囲で行動を選ぶ
   - 🧴 スキンケア / 🏃‍♀️ 運動 / 👗 ファッション研究 / 📚 勉強 / 🧘‍♀️ セルフケア / 💆‍♀️ エステ / 💰 バイト / 📸 SNS投稿
   - 行動を選ぶと確認画面が出て、「やる！」でステータスUP
4. 「😴 おやすみ」で次の日へ。日が進むとストーリーやイベントが発生
5. **30日目**にオーディションのステージ！ 魅力（5ステータスの平均）でエンディングが変わります

## できること

- ブラウザだけで完結（サーバー不要・アカウント不要）
- 進行は端末内に自動セーブ（「つづきから」で再開）
- オフライン動作・ホーム画面に追加できる PWA
- データは端末内だけに保存（サーバー送信なし）

## 動かし方（開発）

静的サイトなのでファイルを開くだけで動きます。PWA を正しく動かすには `localhost` か `https` 配信を推奨。

```bash
python3 -m http.server 8000   # → http://localhost:8000/bakubijo/
```

## 1ファイル版 / クラウドアーティファクト

`standalone.html` は CSS・JS をすべて埋め込んだ**自己完結の1ファイル版**です。外部ファイル参照がないので、ダブルクリックするだけでローカルで遊べ、Claude のクラウドアーティファクトとしてもそのまま公開できます。
