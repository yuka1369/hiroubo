ツイ廃マーケター / network targeting

本物のツイートで、刺さる相手にTOP出しする

CLIが X API で集めた本物のデータ（data/ のJSONL）を読み込み、 各ターゲットのタイムラインに最も“溶け込む”自分のツイ廃履歴を、ブラウザ内のTF-IDF類似度でTOP出しします。 APIキーはCLI側だけ＝このページには入れません（安全）。

CLI で python3 tmark.py run --config config.json（または collect）を実行すると、 data/ に下記が出力されます。その2〜3ファイルを選ぶだけ。ファイルはこのページ内だけで処理され、どこにも送信されません。
いまはサンプルデータを表示中。「本物データを読み込む」タブから、CLIが出力した data/ のJSONLを読み込めます。
