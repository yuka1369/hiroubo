ツイ廃マーケター / how it works

内部アルゴリズムの仕組み

やっていることは一貫して「テキストをベクトルにして、近さ（コサイン類似度）で測る」。 その上に、Xがネットワーク（グラフ）で表示を決めるという前提を重ねています。

核心の仮説：あるユーザーのタイムラインには、その人のネットワーク（絡む相手）に流れている内容が出る。 だから「その人のTLに一番溶け込む自分の過去ツイート」をTOP出しすれば、それが最も表示されやすい候補になる。

FOUNDATION
土台：テキスト → ベクトル → 類似度

形態素解析（MeCab等）を使わず、日本語は文字bigram（2文字ずつ）、英数字は単語に分解します。 各語をTF-IDFで重み付けし、正規化してベクトルにします。

入力「通知が消える」
bigram → 通知知がが消消ええる
TF-IDF → 各語に重み（ありふれた語は軽く、特有の語は重く）
語の重み（TF-IDF） weight(語) = tf × idf
tf = 語の出現数 / 文書の総語数
idf = log( (1 + 文書数N) / (1 + その語を含む文書数df) ) + 1
2つの文書の近さ（コサイン類似度・0〜1） cos(A, B) = Σ Aᵢ·Bᵢ ／ ※A,Bは長さ1に正規化済みなので内積がそのまま類似度

この「cos()」が、以降ぜんぶのステップで共通の“近さ”のものさしになります。

CORE
ユーザー別「TOP出し」の仕組み

ここが心臓部です。ターゲット1人ごとに、自分の全ツイートを「その人のTLへの近さ」で並べ替えます。

狙う順番を決める reach_score

ユーザーは「TOP1本がどれだけ刺さるか（類似度）」と「そのネットワークにどれだけ入り込めそうか（隣人の数）」で並べます。

狙うべきユーザー順（reach_score が高い順） reach_score = 最大類似度 × ( 0.6 + 0.4 × min(1, 隣人数 / 4) )

→ 類似度をベースに、ネットワーク到達性で最大 +40% ブースト。 絡む相手（＝グラフの入口）が多い人ほど、その隣人経由で自分の投稿が届きやすい、という補正です。

ACTIONS
表示率アップの施策（Xアルゴリズムの既知シグナル）

Xが公開したランキングアルゴリズムの重み付けをルール化し、自アカウントを診断して施策を出します。
