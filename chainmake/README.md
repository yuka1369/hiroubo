# 🔗 ChainMake

**〇〇のあとは、〇〇。習慣を鎖でつなぐ習慣化アプリ。**

「起きたら → カーテンを開ける → 布団をたたむ → 机をリセット → **ベッドメイキング！**」のように、
すでにやっている行動のあとに次の行動をくっつけていく **チェーンメイク（習慣の連鎖 / habit stacking）** メソッドの習慣化アプリです。
意志の力にたよらず、きっかけ（トリガー）から一気にゴールまで走りきることを狙います。

## コンセプト

朝のうちに掃除して、最後は「ベッドメイキング！」まで到達する。
バラバラだと続かない一つひとつの行動を、**1本のチェーン**にまとめて、
「つぎのひとつ」だけに集中しながら順番にこなしていきます。

## 使い方

1. `index.html` をブラウザで開く（スマホ推奨）
2. 初回は例として「朝のベッドメイキング」チェーンが入っています
3. **「＋ 新しいチェーン」** で自分のルーティンを作る
   - **きっかけ（トリガー）**：これをしたら始める合図（例：ベッドから出たら）
   - **つなげる行動**：上から順にこなす小さな行動を並べる
   - **ゴールのかけ声**：やり切ったときの一言（例：ベッドメイキング！）
4. **「▶ はじめる」** でフォーカスモードへ。画面には「つぎのひとつ」だけが大きく出ます
5. できたら **「できた！ 👇 つぎへ」**。最後まで行くと 🎉 かけ声＆連続日数（ストリーク）が更新されます

## できること

- チェーン（ルーティン）の作成・編集・削除
- 「きっかけ → 行動 → 行動 → ゴール」の鎖ビュー
- 1ステップずつ進むフォーカス実行モード（進捗バー付き）
- 毎日の達成記録と 🔥 連続日数（ストリーク）
- バイブによる小さなフィードバック（対応端末のみ）
- オフライン動作（PWA / Service Worker）
- データはこの端末の中だけに保存（サーバー送信なし）

### スマホアプリとして使う（おすすめ）

1. Safari / Chrome で `index.html` を開く
2. 共有メニュー →「ホーム画面に追加」
3. ホーム画面のアイコンから起動

## 動かし方（開発）

静的サイトなので、サーバー不要でファイルを開くだけでも動きます。
Service Worker（オフライン）をきちんと使うには `https` か `localhost` での配信が必要です。

```bash
# 例: どれか1つ（このディレクトリで）
python3 -m http.server 8000     # → http://localhost:8000
npx serve .
```

## ファイル構成
